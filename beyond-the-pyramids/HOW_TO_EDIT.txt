BEYOND THE PYRAMIDS — HOW TO EDIT THIS WEBSITE
================================================
You do not need to know how to code. Follow this guide.

1. OPENING THE SITE
   Double-click "index.html". It opens in your web browser.
   That's it — no installation, no setup.

2. THE THREE FILES THAT MATTER
   - index.html        → all the text and structure
   - css/style.css      → all the colours, fonts, spacing
   - js/script.js       → the animations (you shouldn't need to touch this)

3. EDITING TEXT
   Open index.html in any text editor (Notepad, TextEdit, or VS Code).
   Use Ctrl+F / Cmd+F to search for a comment like:
       <!-- CHANGE TITLE -->
       <!-- WRITE INTRODUCTION -->
   The line just below the comment is what shows on the site.
   Replace the text between [square brackets] with your own writing,
   then save the file and refresh your browser.

4. ADDING A PHOTO
   a) Put your image file inside the "images" folder.
      Give it a simple name with no spaces, e.g. "before-pyramids.jpg".
   b) In index.html, find the placeholder box you want to replace, e.g.:
        <div class="placeholder-box">INSERT PHOTO<br><span>...</span></div>
   c) Replace that whole line with:
        <img src="images/before-pyramids.jpg" alt="Describe the photo">
   d) Save and refresh.

5. ADDING A GRAPH
   Export your graph from Excel/Google Sheets as a PNG or JPG image,
   put it in the "images" folder, then follow the same steps as
   "Adding a photo" above, replacing the graph placeholder box.

6. ADDING A VIDEO (interview or documentary clip)
   Easiest method — upload your video to YouTube (can be "unlisted"
   so only people with the link can see it), then:
   a) On YouTube, click Share → Embed, and copy the code that starts
      with <iframe ...>.
   b) In index.html, find the placeholder box for that video, e.g.:
        <div class="placeholder-box video-box">INSERT VIDEO...</div>
   c) Replace it with the <iframe> code you copied.
   d) Save and refresh.

7. ADDING MORE INTERVIEW CARDS, TIMELINE ENTRIES, OR POLICY CARDS
   Find a comment that says "DUPLICATE ... block above to add more".
   Select the whole block just above it (from the opening tag to its
   matching closing tag), copy it, paste it directly below, and edit
   the copy's text.

8. CHANGING COLOURS
   Open css/style.css. At the very top you'll see a list like:
        --navy:  #0B1E3A;
        --gold:  #C9A227;
   Change the six-character code after any colour to change it
   everywhere on the site at once. Use a site like coolors.co or
   the colour picker in Word/PowerPoint to find a hex code.

9. THE HERO (HOME) BACKGROUND
   The homepage currently uses a cream / off-white background with a
   subtle gold pattern. If you'd like a photograph behind the title
   instead, open css/style.css, find the ".hero" rule near the top of
   the HERO section, and add this line inside it:
        background-image: url('../images/your-photo.jpg');
        background-size: cover;
        background-position: center;

10. IF SOMETHING BREAKS
   If the page stops working after an edit, it's almost always a
   missing closing bracket ">" or quotation mark. Undo your last
   change (Ctrl+Z) and try again more carefully, editing one thing
   at a time.

Enjoy building your exhibition.
